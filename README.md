# Gerenciador de Tarefas em Python 3

Projeto desenvolvido como parte da avaliação da disciplina **Linguagem de Programação** da Universidade Federal Rural de Pernambuco (UFRPE).

## 📚 Sobre o Projeto

Este é um simples **Gerenciador de Tarefas** feito em **Python 3**, com o objetivo de aplicar os conceitos estudados durante a disciplina. O programa permite que o usuário cadastre, edite, liste, conclua e exclua tarefas, tudo através de um menu interativo no terminal.

> **Desenvolvido por:**

> - Leticia Rebeka Ferreira Felix 💖

## 🚀 Funcionalidades

- ✅ Cadastrar nova tarefa
- 📋 Listar tarefas pendentes
- 🗂️ Listar tarefas concluídas
- ✏️ Editar descrição da tarefa
- ✔️ Marcar tarefa como concluída
- ❌ Excluir tarefa
- 🔚 Sair do programa

## 💻 Tecnologias Utilizadas

- **Python 3** (sem bibliotecas externas)

## 📝 Como Executar

1. Certifique-se de ter o **Python 3** instalado na sua máquina.

2. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/seu-repositorio.git
   ```

3. Navegue até a pasta do projeto:
   ```bash
   cd gerenciador-de-tarefas
   ```

4. Execute o script:
   ```bash
   python gerenciador_tarefas.py
   ```
